# Changelog

## 0.0.1-beta: first public release

- **The whole game is in English:**
  - all 13,425 story lines (main story, Hell scenes, staff episodes and side scenes) and every speaker name;
  - menus, tutorials, and the item, skill, enemy, Hell and work-area data;
  - the in-game manual.
- **Images:** the 26 chapter title cards are redrawn in English.
- **Manual:** an English copy of the game's HTML manual is installed in `Manual (English)`.
- **Menus:** labels are fitted to their boxes. Some long names are shortened, and some fonts are made smaller or more tightly spaced.
- **Installer:**
  - Put it in the game folder and run it. It finds the game by itself, checks that the game version matches, and shows the license.
  - The uninstaller brings back the Japanese game. Silent install: `/S`.
- **Known issues:** see the README.
